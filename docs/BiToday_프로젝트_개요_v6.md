# 프로젝트 개요

본 문서는 요구사항분석서 v6 기준입니다.

**BiToday**는 가상 포인트로 암호화폐 선물(Futures) 포지션을 거래하는 모의투자 플랫폼입니다.
롱/숏 · 레버리지(1/5/25/125배) · 격리 증거금 · 헤지 모드 · 자동 청산
수익화 목적 없는 포트폴리오/취미 프로젝트로, 구현 완료 시 배포

- **성격**: 비상업용 개인 프로젝트

# 학습 목표

기능 완성이 아닌 대용량 트래픽에서의 동시성 제어 · 데이터 정합성 · 성능 최적화가 목적
부하의 원천은 업비트 시세 수신(읽기 전용 스트림)이 아니라 포지션 진입/종료/청산의 DB 쓰기 경합
